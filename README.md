# 💍 LOVE QUEST : 영원의 파티 (`pixel-wedding-quest`)

16-Bit 레트로 포켓 RPG 게임기 컨셉으로 제작된 **인터랙티브 모바일 웨딩 청첩장** 프로젝트입니다.
하객들이 직접 신랑·신부 파티를 조작해 **웨딩빌리지(Wedding Village)**의 7개 랜드마크를 탐험할 수도 있고, 어르신·바쁜 하객분들을 위해 **한눈에 보기(클래식 스크롤 모드)**로도 즉시 전환할 수 있는 듀얼 모드 구조입니다.

---

## ✨ 핵심 개성 & 주요 기능

1. **🎮 2D 탑다운 RPG 마을 탐험 (`VillageCanvas.tsx`)**
   - 벚꽃잎이 흩날리는 픽셀 광장 위로 **신랑(성기사) + 신부(아크메이지) + 반려묘(모찌)**가 JRPG 파티 대열을 이루어 함께 걸어 다닙니다.
   - **조작 방식 3가지 완벽 지원**:
     - 맵 위의 건물이나 땅을 **직접 터치/클릭**하면 자동 길찾기 이동 후 건물 입장
     - 화면 하단의 **휴대용 게임기 십자키(D-Pad) + [A]/[B] 버튼** 조작
     - PC 환경 **방향키 / WASD + Space / Enter** 및 **⚡ 순간이동 포탈 바** 지원
2. **📜 듀얼 모드 (`마을탐험 모드` ↔ `한눈에 보기 스크롤 모드`)**
   - 게임 조작이 낯선 어르신이나 빠른 정보 확인을 원하는 하객을 위해 상단 **[한눈에보기]** 버튼 클릭 시 모든 섹션이 한 페이지로 펼쳐집니다.
3. **🎵 무설치 순수 WebAudio 8-Bit 칩튠 신디사이저 (`soundEngine.ts`)**
   - 외부 음원 파일 없이 WebAudio 오실레이터로 직접 합성한 **8-Bit 캐논 변주곡 웨딩 BGM**과 발자국, 코인, 팡파레 효과음을 재생합니다.
4. **🏛️ 웨딩빌리지 7대 퀘스트 랜드마크**
   - **📜 모험가 길드 (`StorySection.tsx`)**: 초대의 말씀, 신랑·신부 LV.99 캐릭터 스탯 카드, 혼주 직통 전화/문자 연결, 연애 퀘스트 타임라인
   - **🏰 웨딩 대성당 (`CeremonySection.tsx`)**: 실시간 D-Day 디지털 시계탑, 픽셀 달력, `.ics` 스마트폰 캘린더 일정 저장, 본식 타임테이블
   - **🖼️ 기억의 박물관 (`GallerySection.tsx`)**: HD 웨딩 스냅 감상 & **실시간 16-Bit 도트 씬 변환 스위치**, 사진별 축복 하트 투표
   - **🗺️ 마법 정류장 (`LocationSection.tsx`)**: 픽셀 레이더 약도, 네이버 지도 / 카카오맵 / 티맵 원클릭 길찾기, 도로명 주소 복사, 교통편 공략집
   - **🏦 골드 은행 (`GiftSection.tsx`)**: 신랑측/신부측 계좌번호 복사 시 코인 효과음 + 꽃가루 + `+999 LUCK` 버프 토스트 연출
   - **⛲ 축복의 분수대 (`MiniGameSection.tsx`)**: 20초 아케이드 **부케 & 반지 캐치 미니게임** + **신랑·신부 TMI 퀴즈** (클리어 시 방명록 전용 특별 칭호 획득!)
   - **🏕️ 모험가 주점 (`RsvpGuestbookSection.tsx`)**: 6종의 도트 하객 클래스(성기사, 마법사, 궁수, 음유시인, 프리스트, 고양이) 선택 후 참석 의사(RSVP)와 축하 글을 남기면 **마을 광장에 내 캐릭터와 말풍선이 실시간 소환**됩니다!
5. **🛠️ 실시간 커스텀 에디터 (`CustomizerModal.tsx`) & 단일 설정 파일 (`weddingConfig.ts`)**
   - 우측 상단 **렌치(🛠️) 아이콘**을 눌러 브라우저에서 바로 신랑·신부 이름, 턱시도/헤어 컬러, 예식일, 웨딩홀 주소를 수정해보고 JSON으로 내보낼 수 있습니다.

## 🚀 실행 방법

```bash
# 패키지 설치
bun install   # 또는 npm install

# 개발 서버 실행 (http://localhost:5177)
bun run dev   # 또는 npm run dev

# 프로덕션 빌드
bun run build
```
